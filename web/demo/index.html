A workflow you can follow.

AISMR turns one everyday object into twelve sensory scenes and one finished video. LangGraph coordinates the plan, your reviews, video generation, narration and editing.

The working screen shows recorded activity and saved outputs. Select a step to inspect its history; return to the current step to follow new work. Browsing history does not interrupt the run.

The seven steps

    What the activity shows

    Entries come from saved application events. Times describe when those events were recorded. Agent activity distinguishes a submitted request, a received result and a validated result. Renderer updates show observed preparation, frame rendering, encoding and verification. Percentages describe renderer work, not the whole workflow. Older runs may have fewer updates. These records do not expose model thinking.

    Sample mode uses fixture plans and media. Recorded mode replays earlier media. Both are labeled in the studio. Newly generated video requires the live providers to be enabled.

    In a production run, plan approval starts production. Accepting an eligible final video also permits it to appear in the public library, which keeps up to three results. Opening or watching a video does not give that permission.

    Run allowances are application accounting, not provider billing caps. Unresolved charges are not treated as free. Application episodic memory is not available in this walkthrough; coding-agent memory is separate.
